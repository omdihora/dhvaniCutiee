## 🌟 About The Project

**RelationshipOS** is an ultra-premium, cinematic, and interactive digital fairytale created by **Om** for **Dhvani**. It bridges physical distance by unifying milestones, heartfelt memories, interactive games, 3D WebGL worlds, and comforting sanctuaries into an unforgettable digital experience.

---

## 🏡 Special Highlight: Dhvani's Recovery Room ❤️

A calm, cozy, and comforting standalone sanctuary created specifically for Dhvani while resting and recovering from a fever:

- 🌧️ **Cozy Bedroom Atmosphere**: Muted blush pink, dusty rose, champagne, and warm amber candlelight. Layered rainy window with moving clouds, distant lightning flashes, swaying linen curtains, and gentle floating fireflies.
- 🎵 **Procedural Ambient Sound Engine**: 100% offline Web Audio API synthesizer producing soft indoor rain, rolling distant thunder, and relaxing Lydian piano chords with independent mute controls.
- 🧸 **Virtual Hug ("Hold My Hand ❤️")**: Press-and-hold interaction with an animated charging ring where the teddy opens its arms wide to deliver a virtual hug.
- ☕ **Bedside Virtual Care Package**: Clickable comfort items (Glass of Water 💧, Warm Tea 🍵, Hot Soup 🍲, Teddy Bear 🧸, Fresh Flower 🌸, and a handwritten Heart Note 💌).
- ⚡ **Dhvani Health System**: Playful developer telemetry (Energy Battery, Mood Protection, Blanket Fluff Level, and Om's Concern fixed at 100% with `REST REQUIRED ❤️`).
- 🌤️ **Mood Weather Customizer**: Adapts the bedroom environment to how Dhvani feels (☀️ *Feeling Better*, 🌤️ *I'm Okay*, 🌧️ *Not Feeling Good*, 🌙 *Just Tired*).
- 🌺 **Growing Recovery Flower**: Tracks recovery progress across visits from Seed 🌱 to Full Bloom 🌺.
- 🎙️ **Om Left You a Message**: Vintage cassette player with spinning reels that plays a gentle lullaby or custom recorded voice memos.
- 🌙 **Rest Mode & Calming Breathing Circle**: Dims the screen, slows animations, and guides a soothing breathing rhythm (*"Breathe in... Hold... Breathe out..."*) to encourage peaceful sleep.

> **Direct Access**: Add `#recovery` to the URL or click the **`❤️ Recovery`** button in the floating dock.

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Vanilla CSS Design System, Glassmorphism
- **3D Graphics & Animations**: Three.js (WebGL World Canvas), Framer Motion, GSAP
- **Audio**: Web Audio API Procedural Synthesizer (Zero external audio asset dependencies)
- **Icons**: Lucide React
- **Deployment**: Vercel

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/omdihora/dhvaniCutiee.git
cd dhvaniCutiee
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
